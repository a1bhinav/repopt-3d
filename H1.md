# Optimization-Guided Adaptation of Pretrained Visual Representations for 3D Scene Understanding

## Overview
This project investigates how to adapt pretrained 2D visual features after lifting them into 3D point clouds using multi-view projection. The core idea is to improve 3D semantic segmentation performance in a label-scarce setting without training a full 3D model.

The approach builds on OpenScene, which lifts 2D features into 3D space. Instead of retraining a heavy backbone, this work introduces a lightweight optimization-based adapter with carefully designed regularization.

---

## Abstract Summary
The project studies whether a small optimization layer on top of frozen 3D features can recover segmentation quality. It focuses on:
- Sparse supervision
- Lightweight adaptation
- Interpretable optimization objectives

Three key regularizers are introduced:
- Graph smoothness
- Confidence-masked entropy
- Trust-region penalty

Each is tied to a hypothesis and diagnostic metric.

---

## Background and Prior Work

### 1. OpenScene
OpenScene lifts pretrained 2D image features into 3D point clouds using calibrated multi-view fusion.

Key points:
- Uses pretrained vision models (e.g., CLIP)
- Produces semantically rich 3D features
- No need for full 3D training
- Limitation: noisy predictions, especially at boundaries and low-coverage regions

### 2. 3D Semantic Segmentation
Traditional methods:
- PointNet++
- MinkowskiNet

Characteristics:
- Require full supervision
- Train heavy 3D models
- High computational cost

This project differs by:
- Keeping features frozen
- Only adapting a small module

### 3. Pretrained Visual Features
Relevant models:
- CLIP
- DINOv2
- MAE

Insight:
Pretrained representations contain strong semantic priors that can transfer to new tasks.

### 4. Graph-Based Regularization
Based on Laplacian regularization:
- Assumes nearby points should have similar labels
- Uses k-NN graph over 3D coordinates

### 5. Entropy Minimization
Inspired by:
- Semi-supervised learning
- TENT (test-time adaptation)

Idea:
- Encourage confident predictions on unlabeled data
- Avoid low-confidence regions

## Problem Setup

Given:
- 3D point cloud P
- Features z_i from OpenScene
- Small labeled subset L
- Large unlabeled subset U

Goal:
Learn:
- Adapter g_θ
- Classifier h_ψ

Prediction:
ŷ_i = h_ψ(g_θ(z_i))

Constraints:
- Very few labels
- Must preserve pretrained structure

---

## Core Idea

Instead of retraining a full 3D model:
- Keep pretrained features frozen
- Learn a small adapter
- Use optimization constraints to guide learning

This turns the problem into:
- A constrained optimization problem
- With interpretable components

---

## Hypothesis 1 (H1): Boundary Incoherence

### Problem
Nearby points belonging to the same surface receive inconsistent predictions near object boundaries.

### Cause
- Multi-view fusion averages features from different viewpoints
- Misalignment across views
- Leads to ambiguous features at boundaries

### Intuition
- Feature lies between classes
- Classifier becomes sensitive to small perturbations

### Goal
Enforce spatial consistency across nearby points

---

## Optimization Framework

### Model
- Adapter: small residual MLP
- Classifier: linear + softmax
- Frozen backbone

### Objective Function

J(θ, ψ) = L_sup + λ1 L_graph + λ2 L_ent + λ3 L_tr

---

## Components

### 1. Supervised Loss
- Cross-entropy on labeled points
- Only term using ground truth

---

### 2. Graph Smoothness (Targets H1)

Encourages:
- Nearby points → similar predictions

Mechanism:
- Build k-NN graph in 3D space
- Penalize prediction differences

Effect:
- Reduces boundary noise
- Enforces local consistency

---

### 3. Confidence-Masked Entropy

Encourages:
- Confident predictions on reliable unlabeled points

Key idea:
- Only use points with low entropy
- Ignore uncertain predictions

---

### 4. Trust-Region Penalty

Encourages:
- Minimal deviation from pretrained initialization

Effect:
- Prevents overfitting
- Stabilizes training

---

## Why This Works

Each component targets a failure mode:

- Graph smoothness → fixes boundary inconsistency
- Entropy → leverages reliable unlabeled data
- Trust region → prevents drift
